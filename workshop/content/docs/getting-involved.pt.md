# Envolver-se

Existem inúmeras formas de se envolver com o desenvolvimento da OGC APIs. Se deseja assistir às reuniões do Grupo de Trabalho de Normas (SWG) e fazer parte do componente mais formal do desenvolvimento de normas (incluindo votação), é necessária uma [membro da OGC](https://www.ogc.org/join/). No entanto, existem outras oportunidades para se envolver que não exigem uma adesão à OGC. Apresentamos algumas dessas abaixo.

## Especificações / GitHub

A maioria do desenvolvimento da OGC API ocorre em [repositórios GitHub](https://github.com/orgs/opengeospatial/repositories?q=ogcapi&type=all&language=&sort=) públicos. Isto significa que qualquer pessoa pode acompanhar o desenvolvimento das normas, desde as suas fases iniciais e até mesmo contribuir através dos mecanismos habituais (por exemplo: rastreador de issues, pull requests)

![imagem](assets/images/oaf-issue-tracker.png){width="100.0%"}

## Code sprints da OGC

As Code sprints da OGC são uma parte importante do processo de desenvolvimento de normas, uma vez que proporcionam um ciclo de feedback da comunidade de programadores. Durante estes eventos, membros do grupo de trabalho e programadores unem esforços em direção ao objetivo comum de impulsionar o desenvolvimento das normas. Isto é feito através de discussões e prototipagem. Estas são algumas características das code sprints:

* Realizadas regularmente (cerca de três vezes por ano)
* Eventos colaborativos de três dias, virtuais/híbridos
* Inclusivos para todas as normas da OGC
* Frequentemente co-organizados com parceiros de aliança (por exemplo: [ISO](https://www.iso.org/home.html), [OSGeo](https://www.osgeo.org/), [ASF](https://www.apache.org/))
* Envolvem programadores de todo o mundo
* Incluem uma vertente de mentoria, para integrar recém-chegados
 
![Code sprint em Londres, outubro de 2023](assets/images/code-sprint-london.jpeg){width="100.0%"}

!!! note "Não *apenas* código!"
    Embora a maioria dos participantes passe tempo a programar (essa é a "razão" pelo qual se chama code sprint, afinal), também damos as boas-vindas a atividades sem código, como trabalhar em documentação, testes ou issues no GitHub.

## Servidor Discord de Eventos da OGC

O [servidor Discord de Eventos da OGC](https://discord.gg/3uyaZZuXr3) fornece uma plataforma para realizar as code sprints. A sua estrutura de canais facilita discussões focadas e aproveitamos os canais de áudio para realizar as reuniões das code sprints. Entre code sprints, o servidor Discord também fornece um ponto de encontro para discutir tópicos relacionados com o desenvolvimento e implementações de normas da OGC.

![Code sprint em Londres, outubro de 2023](assets/images/discord-2023-10-30.png){width="100.0%"}
