# Conformidade e certificação

![Compliance badge](assets/images/Certified_OGC_Compliant_Logo_Example.gif){width="40.0%"}

O [Programa de Conformidade do OGC](https://www.ogc.org/compliance) fornece os recursos, procedimentos e políticas para certificar produtos quanto à conformidade com um ou mais padrões do OGC.

O objetivo principal do programa é aumentar a interoperabilidade de sistemas enquanto reduz os riscos tecnológicos, fornecendo um processo pelo qual a conformidade com os padrões do OGC pode ser testada.

Pode navegar na [página de produtos de conformidade do OGC](https://portal.ogc.org/public_ogc/compliance/compliant.php?display_opt=1&org_match=Crunchy+Data) para verificar a lista de produtos certificados pelo OGC.

## TEAM Engine

A fim de ser certificado, um produto precisa de passar os testes no validador do OGC. A infraestrutura de validação do OGC é baseada no [TEAM Engine](https://github.com/opengeospatial/teamengine), uma ferramenta Livre e de Código Aberto que está a ser incubada como um [projeto da OSGeo](https://www.osgeo.org/projects/teamengine/).

Os desenvolvedores podem usar a versão alojada do TEAM Engine no CITE, ou instalar e integrá-lo localmente na sua própria pipeline.

!!! note "Suites de teste OGC API"
    Referiremos as suites de teste disponíveis no contexto de cada padrão, durante o Aprofundamento OGC API.

## Implementações de referência

Uma implementação de referência (IR) é uma cópia totalmente funcional, licenciada de um software testado e de marca que passou o teste para uma classe de conformidade associada numa versão de um Padrão de Implementação e que é livre e publicamente disponível para teste via serviço web ou transferência.

* As IR não precisam de estar conformes com todas as classes de conformidade do padrão, mas devem conformar pelo menos com o núcleo.
* A IR deve estar disponível, num servidor fiável que tenha um limiar alto de disponibilidade.
* O OGC fornecerá um incentivo às duas primeiras IR que passarem o teste relacionado com uma classe de conformidade dentro de uma versão de um Padrão de Implementação

Mais informação sobre IR está disponível em [Políticas e Procedimentos do Programa de Testes de Conformidade](https://docs.ogc.org/pol/08-134r11.html#toc26).

## Resumo

A conformidade e certificação OGC fornecem a uma organização um nível de confiança de que um produto foi considerado compatível para
máxima interoperabilidade contra uma especificação OGC dada.
