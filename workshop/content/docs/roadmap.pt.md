# OGC API Roadmap

O [OGC Standards Roadmap](https://agora.ogc.org/roadmap) destaca os esforços atuais e planeadas de normas, bem como extensões relacionadas com essas normas. O Roadmap
é útil para planear novas funcionalidades para os utilizadores, bem como a implementação de software.

!!! note
    O OGC Standards Roadmap fornece o estado e cronograma de todas as normas da OGC. Para filtrar o Roadmap apenas para OGC APIs, utilize a caixa de texto "Filter by title, repo, label..." (canto superior esquerdo) e filtre por "OGC API"
